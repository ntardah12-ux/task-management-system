# Task Management System

## Description
A simple Python program that displays a to-do list. Each task has a title, a priority (High, Medium, or Low), and a completion status (Completed or Pending).

## How to Run
1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run: `python main.py`
